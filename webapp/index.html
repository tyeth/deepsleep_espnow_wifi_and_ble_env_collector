Fully offline after the first online visit (HTTPS copy, e.g. GitHub Pages): the page, demo data, Plotly, and the ~10MB Pyodide runtime are downloaded once into the offline cache in the background and reused forever ("offline: ready" chip). Chrome's built-in AI model is likewise a one-time on-device download (managed by Chrome) and answers offline. Datasets live in IndexedDB on this device. On the device-hosted copy (plain http) there is no offline cache - CDN libraries need internet there. HTTPS pages cannot fetch a plain-http device (mixed content) - use BLE there, or open the device-hosted copy.
